# GEfinanças

App mobile de gestão de pedidos, notas fiscais e retirada de materiais.

## Ferramentas
- React
- TypeScript
- Vite

## Como rodar
1. Instale as dependências: `pnpm install`
2. Inicie o projeto: `pnpm dev`
3. Abra o endereço que aparecer no terminal (geralmente http://localhost:5173)
